# Canonical Question Store, Bounded Rephrase, and Resume Preference

**Date:** 2026-07-17  
**Branch:** `uthman`  
**Status:** Implemented  

---

## Intentional (unchanged)

- Soft “next question” / “move on” stays on the current domain.
- Hard skip remains budgeted.
- Coverage-first wrap-up remains.

## Fixed

### Prompt stacking
Guards no longer rebuild recoveries from the previous full TTS string.  
`InterviewContext.current_canonical_question` stores the clean one-sentence intent.  
Recoveries speak from that store via `dialogue/rephrase_policy.py`.

### Same intent, fresh wording
Repeat / clarify / redirect / IDK-1 use a bounded rephrase helper (LLM when available, single-paste fallback otherwise).

### IDK hints
Longer “I don’t know… pass” utterances are detected so `IdkGuard` wins before domain redirect.  
Attempt 2 reliably includes `Here's a small hint:` plus one fresh ask.

### Bounded LLM domain asks
Hardcoded domain map is now an **intent seed / fallback**. Primaries are generated by Groq with domain + seed constraints, then fall back to the seed if needed.

### Resume preference
Resume parsing extracts projects, maps evidence to blueprint domains (`resume_by_domain`), and injects that evidence into domain question prompts. On-domain resume questions are preferred when tagged for the active domain.
